# Hi, I'm 小欣 👋

我在 **AI × Art × Creative Technology** 的交叉位置做项目，关注生成式 AI、创意工具、交互体验与工作流自动化。

本科毕业于湖北美术学院影像媒体艺术专业，研究生毕业于伦敦艺术大学创意产业的人工智能与数据分析专业。

## Selected Projects

### [AI 模拟面试器 · ai-mock-interview](https://github.com/littlexx15/ai-mock-interview)

根据简历、作品集与职位描述生成针对性问题，支持模拟面试、追问、多维度复盘与完整日志导出。

### [英语习语接龙 · Idiomix](https://github.com/littlexx15/Idiomix)

一个终端聊天机器人游戏，通过英语习语接龙、计分与反馈，让词汇练习更像一次轻松的对话。

### [绘画转音乐实验室 · MetaTone Lab](https://github.com/littlexx15/MetaTone-Lab)

把自由绘画与视觉特征转化为歌词和完整音乐的交互式生成 AI 实验。

### [窗边麻糬桌面宠物 · mochimochi-cat](https://github.com/littlexx15/mochimochi-cat)

一只会散步、撒娇、玩耍和陪伴工作的轻量桌面小猫，支持网页房间与 Windows 透明悬浮窗口。

### [提示词口袋 · prompt-pocket](https://github.com/littlexx15/prompt-pocket)

完全在浏览器本地运行的个人提示词与案例素材库，支持搜索、分类、变量替换、收藏和数据备份。

### [自动视频混剪工具 · auto-video-mixer](https://github.com/littlexx15/auto-video-mixer)

面向 Windows 的本地视频生产工具：从中文文案生成配音和字幕，并通过素材调度与 FFmpeg 批量输出短视频。
