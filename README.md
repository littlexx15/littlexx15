# 嗨，我是小欣 👋

我在 **AI、艺术和创意技术** 的交界处做东西。我喜欢生成式 AI、创意工具、交互体验，还喜欢研究怎么把重复的工作流自动化掉！

本科在湖北美术学院学影像媒体艺术，研究生去了伦敦艺术大学，方向是创意产业里的人工智能与数据分析。

## 做过的一些项目

**AI 模拟面试器** · [ai-mock-interview](https://github.com/littlexx15/ai-mock-interview)

上传简历和职位描述，它会针对性地出题、追问、复盘，最后导出完整面试日志。

**英语习语接龙 · Idiomix** · [GitHub](https://github.com/littlexx15/Idiomix)

一个终端里的对话小游戏，用英语习语接龙来练词汇，带计分和反馈。

**绘画转音乐实验室 · MetaTone Lab** · [GitHub](https://github.com/littlexx15/MetaTone-Lab)

随手画点什么，系统把视觉特征变成歌词和完整音乐。一个关于"看见声音"的交互实验。

## 最近在折腾

生成式 AI、创意编程、计算机视觉、影像工具，以及一切能让重复劳动更轻松的东西。
